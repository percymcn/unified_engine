## Gaps from Current State

Based on the Reality Snapshot, these are the gaps:

### Critical Gaps (Must Fix)
1. **Order Placement** - TradeLocker and ProjectX order placement not tested with real trades
2. **Webhook Routing** - Per-account webhook routing not fully implemented
3. **Alembic Template** - Missing migration template file

### Important Gaps (Should Fix)
1. **Dynamic Forms** - UI still uses hardcoded forms, not credential schemas API
2. **Error Messages** - Many API errors return generic messages
3. **OAuth Refresh** - Tradovate token refresh not verified

### Minor Gaps (Can Defer)
1. **MT4/MT5 Testing** - MetaAPI SDK not tested with real accounts
2. **Strategy Routing** - No UI for strategy-to-account mapping
3. **Observability** - Logging limited, no metrics

## Out of Scope for v1.2

- Mobile app or PWA enhancements
- Multi-tenancy / team features
- CI/CD pipeline setup
- Advanced analytics / backtesting
- Additional broker integrations beyond current 6
- Credit-based pricing / usage metering

## Dependencies

- Real broker credentials for testing (TradeLocker, ProjectX demo accounts)
- Stripe test mode for billing verification
- Local PostgreSQL with trading_db
