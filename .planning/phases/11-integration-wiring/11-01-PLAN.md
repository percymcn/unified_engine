# Plan 11-01: Initialize DI Container in main.py

## Overview

The hexagonal architecture (Phases 3-5) built a complete DI container with use cases, repositories, and adapters, but it was never initialized in the application entry point. This plan wires the container into the FastAPI lifespan to make all use cases available.

## Gap Being Closed

From MILESTONE-AUDIT.md:
- "DI Container never initialized in main.py"
- "All use cases unreachable"
- "Five broker adapters implemented but orphaned"

## Current State

```python
# app/main.py (lines 19, 101)
from app.services.signal_processor import signal_processor

async def lifespan(app: FastAPI):
    # OLD initialization
    await signal_processor.initialize()
```

## Target State

```python
# app/main.py
from app.infrastructure.container import Container

# Global container instance
container: Container | None = None

async def lifespan(app: FastAPI):
    global container
    container = Container()
    await container.initialize()
    app.state.container = container

    yield

    await container.shutdown()
```

## Tasks

### Task 1: Import Container in main.py
- Add import: `from app.infrastructure.container import Container`
- Add global variable: `container: Container | None = None`

### Task 2: Initialize Container in Lifespan
- In the startup section of `lifespan()`, instantiate and initialize the container
- Store container on `app.state.container` for router access
- Keep old signal_processor initialization temporarily for backward compatibility

### Task 3: Add Container Shutdown
- In the shutdown section of `lifespan()`, call `await container.shutdown()`
- This ensures clean disconnection from brokers and event bus

### Task 4: Create Dependency Function
- Create `app/dependencies.py` with:
```python
from fastapi import Request
from app.infrastructure.container import Container

def get_container(request: Request) -> Container:
    return request.app.state.container
```

### Task 5: Verify Startup
- Run `python -c "from app.main import app; print('Container wired')"` to verify no import errors
- Check logs for container initialization messages

## Success Criteria

1. Container initializes on app startup (verify via startup logs)
2. Container shuts down on app shutdown
3. `app.state.container` accessible from any router
4. All 5 broker adapters initialized (check container._broker_adapters)
5. All use case factories callable (container.process_signal_use_case(), etc.)
