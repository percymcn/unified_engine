# Plan 09-03: API Keys Management

## Context

Phase 9 success criterion: "API keys can be created, viewed (masked), and revoked".

Backend already has full API key management at `/api-keys/`:
- GET / - List all API keys (masked)
- POST / - Create new API key (returns key once)
- DELETE /{key_id} - Revoke API key
- GET /{key_id} - Get key details (masked)

## Goal

Build UI for managing API keys with create, view (masked), and revoke functionality.

## Prerequisites

- Phase 8 complete (dashboard foundation)
- Backend `/api-keys/` endpoints working

## Tasks

### Task 1: Create API Key Types
Define TypeScript interfaces for API key data.

**File**: `ui-next/src/types/api-key.ts`
```typescript
export interface ApiKey {
  id: number;
  name: string;
  is_active: boolean;
  expires_at?: string;
  last_used_at?: string;
  created_at: string;
  permissions: string[];
}

export interface ApiKeyCreate {
  name: string;
  expires_days?: number;
  permissions?: string[];
}

export interface ApiKeyCreateResponse extends ApiKey {
  api_key: string; // Only returned on creation
}
```

## Notes

- API key is only shown once on creation - user must copy it
- After creation, key is stored hashed in database
- Revocation is soft-delete (is_active = false)
- Keys with expiration show time remaining
