# Plan 21-03: Multi-Account UI

## Objective

Build the frontend user interface for managing multiple accounts, configuring account settings, creating account groups, and setting up signal routing.

## Context

**Phase Requirements:**
- ACCT-01: Users can connect multiple accounts per broker
- ACCT-02: Users can connect multiple brokers simultaneously
- ACCT-03: Route signals to specific accounts or all accounts
- ACCT-04: Per-account position sizing rules
- ACCT-05: Per-account risk limits
- ACCT-06: Account grouping ("Prop Firm Accounts", "Personal Accounts")

**Existing UI:**
- Account management at `/settings/accounts/` with form at `ui-next/src/components/accounts/account-form.tsx`
- Webhook config at `/settings/webhooks/` with routing rules
- Settings page pattern established in Phase 20 (Symbol Mapping)
- Uses shadcn/ui components, Tailwind CSS

**Dependencies:**
- Plan 21-01: Backend account settings and groups
- Plan 21-02: Routing configuration API

## Tasks

// Routing configuration component
<Card>
  <CardHeader>
    <CardTitle>Signal Routing</CardTitle>
    <CardDescription>
      Choose how signals from this webhook are routed to your accounts
    </CardDescription>
  </CardHeader>
  <CardContent className="space-y-4">
    <RadioGroup value={routing.strategy} onValueChange={handleStrategyChange}>
      <RadioItem
        value="all_accounts"
        label="All Accounts"
        description="Send to all signal-enabled accounts"
      />
      <RadioItem
        value="specific_accounts"
        label="Specific Accounts"
        description="Send only to selected accounts"
      />
      <RadioItem
        value="rules_based"
        label="Rules-Based"
        description="Route based on signal conditions"
      />
      <RadioItem
        value="default_only"
        label="Default Account Only"
        description="Send only to the default account"
      />
    </RadioGroup>

    {/* Strategy-specific configuration */}
    {routing.strategy === 'specific_accounts' && (
      <div className="space-y-2">
        <Label>Select Accounts</Label>
        {accounts.map(account => (
          <div key={account.id} className="flex items-center gap-2">
            <Checkbox
              checked={routing.specificAccountIds?.includes(account.id)}
              onCheckedChange={(checked) => handleAccountToggle(account.id, checked)}
            />
            <span>{account.name || account.broker}</span>
          </div>
        ))}
      </div>
    )}

    {routing.strategy === 'rules_based' && (
      <div className="space-y-4">
        <div className="flex items-center justify-between">
          <Label>Routing Rules</Label>
          <Button variant="outline" size="sm" onClick={addRule}>
            <Plus className="h-4 w-4 mr-1" />
            Add Rule
          </Button>
        </div>

        {routing.rules?.map((rule, index) => (
          <RoutingRuleEditor
            key={index}
            rule={rule}
            accounts={accounts}
            onChange={(updated) => updateRule(index, updated)}
            onDelete={() => deleteRule(index)}
          />
        ))}

        <div className="pt-2 border-t">
          <Select
            label="Default Account (fallback)"
            value={routing.defaultAccountId?.toString() || ''}
            options={[
              { value: '', label: 'No fallback' },
              ...accounts.map(a => ({ value: a.id.toString(), label: a.name || a.broker }))
            ]}
          />
        </div>
      </div>
    )}

    {(routing.strategy === 'default_only' || routing.strategy === 'rules_based') && (
      <Select
        label="Default Account"
        value={routing.defaultAccountId?.toString() || ''}
        options={accounts.map(a => ({ value: a.id.toString(), label: a.name || a.broker }))}
      />
    )}
  </CardContent>
</Card>

// RoutingRuleEditor component
<div className="p-4 border rounded-lg space-y-3">
  <div className="flex justify-between items-center">
    <span className="font-medium">Rule {index + 1}</span>
    <Button variant="ghost" size="sm" onClick={onDelete}>
      <Trash className="h-4 w-4" />
    </Button>
  </div>

  <div className="grid grid-cols-3 gap-2">
    <Select
      label="Field"
      value={rule.condition.field}
      options={[
        { value: 'symbol', label: 'Symbol' },
        { value: 'action', label: 'Action' },
