# Plan 21-01: Multi-Account Backend Infrastructure

## Objective

Enable users to connect multiple accounts per broker and multiple brokers simultaneously by extending the TradingAccount model with proper multi-account support, per-account settings, and account grouping.

## Context

**Phase Requirements:**
- ACCT-01: Users can connect multiple accounts per broker
- ACCT-02: Users can connect multiple brokers simultaneously
- ACCT-04: Per-account position sizing rules
- ACCT-05: Per-account risk limits (max position, daily loss)
- ACCT-06: Account grouping ("Prop Firm Accounts", "Personal Accounts")

**Existing Infrastructure:**
- `TradingAccount` model in `app/models/database_models.py` already supports multiple accounts per user
- `Account` domain entity in `app/domain/entities/account.py`
- `AccountRepository` port with basic operations
- `require_broker_slot` billing check already limits by broker count (not account count)

**Key Insight:** The current system already allows multiple accounts, but lacks:
1. Per-account settings (position sizing, risk limits)
2. Account grouping
3. Signals per-account routing configuration (handled in 21-02)

```python
from pydantic import BaseModel, Field
from typing import Optional
from enum import Enum

class PositionSizingMode(str, Enum):
    FIXED = "fixed"
    PERCENT_BALANCE = "percent_balance"
    PERCENT_EQUITY = "percent_equity"
    RISK_BASED = "risk_based"

class AccountSettingsRequest(BaseModel):
    """Request to update account settings"""
    account_id: int

    # Position sizing
    position_sizing_mode: Optional[PositionSizingMode] = None
    fixed_lot_size: Optional[float] = Field(None, ge=0.01, le=100)
    percent_of_balance: Optional[float] = Field(None, ge=0.1, le=100)
    percent_of_equity: Optional[float] = Field(None, ge=0.1, le=100)
    risk_percent_per_trade: Optional[float] = Field(None, ge=0.1, le=10)

    # Risk limits
    max_position_size: Optional[float] = Field(None, ge=0.01)
    max_daily_loss: Optional[float] = Field(None, ge=0)
    max_daily_loss_pct: Optional[float] = Field(None, ge=0, le=100)
    max_drawdown_pct: Optional[float] = Field(None, ge=0, le=100)
    max_open_positions: Optional[int] = Field(None, ge=1, le=100)
    max_daily_trades: Optional[int] = Field(None, ge=1, le=1000)
    trade_cooldown_seconds: Optional[int] = Field(None, ge=0, le=3600)

    # Grouping
    group_id: Optional[int] = None

    # Routing
    is_signal_enabled: Optional[bool] = None
    signal_priority: Optional[int] = Field(None, ge=0, le=100)

class AccountSettingsResponse(BaseModel):
    """Response with current account settings"""
    account_id: int
    position_sizing_mode: str
    fixed_lot_size: float
    percent_of_balance: float
    percent_of_equity: float
    risk_percent_per_trade: float
    max_position_size: Optional[float]
    max_daily_loss: Optional[float]
    max_daily_loss_pct: Optional[float]
    max_drawdown_pct: Optional[float]
    max_open_positions: Optional[int]
    max_daily_trades: Optional[int]
    trade_cooldown_seconds: Optional[int]
    group_id: Optional[int]
    group_name: Optional[str]
    is_signal_enabled: bool
    signal_priority: int
```

### Task 4: Create Update Account Settings Use Case

**What:** Use case to update account settings atomically.

**Files:**
- `app/application/use_cases/update_account_settings.py` - New use case
- `app/infrastructure/container.py` - Register use case

**Implementation:**
```python
class UpdateAccountSettingsUseCase:
    def __init__(self, account_repository: AccountRepository):
        self._account_repo = account_repository

    async def execute(self, request: AccountSettingsRequest) -> AccountSettingsResponse:
        """Update account settings"""
        # Get account
        account = await self._account_repo.get_by_id(request.account_id)
        if not account:
            raise AccountNotFoundError(f"Account {request.account_id} not found")

        # Update fields from request (only non-None values)
        update_fields = request.dict(exclude_unset=True, exclude={'account_id'})

        # Apply updates
        for field, value in update_fields.items():
            setattr(account, field, value)

        # Save
        await self._account_repo.save(account)

        return self._to_response(account)
```

**Acceptance:**
- Use case updates only provided fields
- Returns updated settings
- Validates account ownership
