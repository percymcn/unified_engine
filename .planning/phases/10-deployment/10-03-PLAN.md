### Task 4: Create Environment Loader Script
Script to load environment-specific config for deployment.

**File**: `scripts/load-env.sh`
```bash
#!/bin/bash
# Usage: source scripts/load-env.sh [development|staging|production]
# Loads environment-specific variables

ENV=${1:-development}
ENV_FILE="deploy/envs/.env.${ENV}"

if [ ! -f "$ENV_FILE" ]; then
    echo "Error: Environment file not found: $ENV_FILE"
    exit 1
fi

export $(grep -v '^#' "$ENV_FILE" | xargs)
echo "Loaded environment: $ENV"
```

### Task 5: Create Deploy Script
Unified deployment script for different environments.

**File**: `scripts/deploy.sh`
```bash
#!/bin/bash
# Usage: ./scripts/deploy.sh [development|staging|production]
# Deploys stack to Docker Swarm with environment-specific config

set -e
ENV=${1:-production}

echo "Deploying unified-engine to $ENV environment..."

# Load environment
source scripts/load-env.sh $ENV

# For production/staging, ensure secrets exist
if [ "$ENV" != "development" ]; then
    echo "Checking Docker secrets..."
    for secret in db_password secret_key jwt_secret credential_encryption_key; do
        if ! docker secret inspect $secret >/dev/null 2>&1; then
            echo "Error: Secret '$secret' not found. Run scripts/create-secrets.sh first."
            exit 1
        fi
    done
fi

# Deploy stack
docker stack deploy -c docker-stack.yml unified-$ENV

echo "Deployment complete. Check status with: docker stack services unified-$ENV"
```

### Task 6: Create docker-compose.override for Development
Local development compose that doesn't require secrets.

**File**: `docker-compose.override.yml`
```yaml
# Development overrides - used automatically with docker-compose up
# Does NOT use Docker secrets, uses local .env file instead
version: '3.8'

services:
  postgres:
    environment:
      POSTGRES_PASSWORD: trading_password  # OK for local dev only
    ports:
      - "5432:5432"  # Expose for local access

  redis:
    ports:
      - "6379:6379"

  api:
    environment:
      - DEBUG=true
      - LOG_LEVEL=DEBUG
    volumes:
      - .:/app  # Live reload
    ports:
      - "8000:8000"
```
