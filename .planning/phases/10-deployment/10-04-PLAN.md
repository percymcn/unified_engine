# Plan 10-04: Docker Stack Update and Health Checks

## Context

Final plan to integrate all Phase 10 work into a production-ready docker-stack.yml:
- Update UI service to use ui-next
- Integrate Docker secrets (from 10-02)
- Add comprehensive health checks
- Ensure stack survives restarts with persistent data

## Goal

Update docker-stack.yml to be production-ready with ui-next, secrets, and health checks.

## Prerequisites

- Plan 10-01 complete (ui-next Dockerfile)
- Plan 10-02 complete (secrets infrastructure)
- Plan 10-03 complete (environment configuration)

## Tasks

### Task 1: Update UI Service for ui-next
Replace old ui/ service with ui-next Next.js app.

**Changes to docker-stack.yml (ui service)**:
```yaml
# Replace old ui service
ui:
  image: 192.168.1.254:5000/unified-engine/ui-next:latest
  build:
    context: ./ui-next
    dockerfile: Dockerfile
  environment:
    - NEXT_PUBLIC_API_URL=http://api:8000
  ports:
    - "3411:3000"  # Next.js runs on 3000
  networks:
    - unified-network
  deploy:
    replicas: 1
    restart_policy:
      condition: on-failure
    resources:
      limits:
        memory: 256M
      reservations:
        memory: 128M
  healthcheck:
    test: ["CMD", "wget", "-q", "--spider", "http://localhost:3000/api/health"]
    interval: 30s
    timeout: 10s
    retries: 3
    start_period: 40s
```

### Task 2: Add Health Checks to All Services
Add comprehensive health checks for Swarm orchestration.

**postgres health check**:
```yaml

  test: ["CMD-SHELL", "pg_isready -U trading_user -d trading_db"]

  retries: 3
```

**redis health check**:

### Task 3: Integrate Secrets into Services
Update all services to use Docker secrets.

**Global secrets declaration**:
```yaml
secrets:
  db_password:
    external: true
  secret_key:
    external: true
  jwt_secret:
    external: true
  credential_encryption_key:
    external: true
  flower_auth:
    external: true
```

**postgres with secrets**:
```yaml
postgres:
  environment:
    POSTGRES_DB: trading_db
    POSTGRES_USER: trading_user
    POSTGRES_PASSWORD_FILE: /run/secrets/db_password
  secrets:
    - db_password
```

**api/celery services with secrets**:
```yaml

  - DB_HOST=postgres
  - DB_PORT=5432
  - DB_NAME=trading_db
  - DB_USER=trading_user

  - db_password
  - secret_key
  - jwt_secret
```

### Task 4: Add Service Dependencies
Ensure services start in correct order with depends_on and healthcheck.

**For Swarm (using deploy.restart_policy + healthcheck)**:
```yaml
api:
  depends_on:
    postgres:
      condition: service_healthy
    redis:
      condition: service_healthy
    nats:
      condition: service_started
```

Note: Swarm doesn't support depends_on, use healthchecks + restart policies instead.

### Task 6: Update Nginx Configuration
Create nginx.conf for reverse proxy.

**File**: `deploy/nginx/nginx.conf`
```nginx
events {
    worker_connections 1024;
}

http {
    upstream api {
        server api:8000;
    }

    upstream ui {
        server ui:3000;
    }

    server {
        listen 80;

        location /api {
            proxy_pass http://api;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
        }

        location /ws {
            proxy_pass http://api;
            proxy_http_version 1.1;
            proxy_set_header Upgrade $http_upgrade;
            proxy_set_header Connection "upgrade";
        }

        location / {
            proxy_pass http://ui;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
        }

        location /health {
            return 200 'ok';
            add_header Content-Type text/plain;
        }
    }
}
```

- Secrets are encrypted at rest in Swarm

- Nginx config version in name allows updates without downtime
