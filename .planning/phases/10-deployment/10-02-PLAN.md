# Plan 10-02: Docker Secrets Integration

## Context

The current `docker-stack.yml` has HARDCODED secrets throughout:
- `POSTGRES_PASSWORD: trading_password`
- `SECRET_KEY=unified-secret-key-2024`
- `CELERY_BROKER_URL` with embedded password
- `flower --basic_auth=admin:Unified2024!`

This is a critical security issue. Docker Swarm secrets provide encrypted storage for sensitive data.

## Goal

Replace all hardcoded secrets with Docker Swarm secrets for secure credential management.

## Prerequisites

- Plan 10-01 complete (ui-next Dockerfile ready)
- Docker Swarm initialized (`docker swarm init`)

## Tasks

### Task 1: Identify All Secrets
Document all secrets that need migration from hardcoded values.

**Secrets to create**:

### Task 2: Create Secrets Creation Script
Script to initialize secrets in Docker Swarm.

**File**: `scripts/create-secrets.sh`
```bash
#!/bin/bash
# Creates Docker secrets from environment or generates random values
# Usage: ./scripts/create-secrets.sh [env-file]

# Generate random 32-char secret if not provided
generate_secret() {
    openssl rand -base64 32 | tr -dc 'a-zA-Z0-9' | head -c 32
}

# Create each secret
echo "${DB_PASSWORD:-$(generate_secret)}" | docker secret create db_password -
echo "${SECRET_KEY:-$(generate_secret)}" | docker secret create secret_key -
echo "${JWT_SECRET:-$(generate_secret)}" | docker secret create jwt_secret -
echo "${CREDENTIAL_ENCRYPTION_KEY:-$(generate_secret)}" | docker secret create credential_encryption_key -
echo "${FLOWER_AUTH:-admin:$(generate_secret)}" | docker secret create flower_auth -

echo "Secrets created. List with: docker secret ls"
```

### Task 6: Update Service Definitions to Use Secrets
Modify each service to mount and use secrets.

**Changes for postgres service**:
```yaml
postgres:
  environment:
    POSTGRES_PASSWORD_FILE: /run/secrets/db_password
  secrets:
    - db_password
```

**Changes for api, celery-worker, celery-beat, funnel-automation**:
```yaml
environment:
  - DATABASE_URL_FILE=/run/secrets/db_url  # Or construct from parts
  - SECRET_KEY_FILE=/run/secrets/secret_key
secrets:
  - db_password
  - secret_key
  - jwt_secret
  - credential_encryption_key
```

**Changes for flower**:
```yaml
flower:
  command: celery -A app.tasks.celery_app flower --port=5555 --basic_auth_file=/run/secrets/flower_auth
  secrets:
    - flower_auth
```
