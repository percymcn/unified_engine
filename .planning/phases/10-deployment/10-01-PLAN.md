# Plan 10-01: Next.js Production Dockerfile

## Context

Phase 10 needs a production-ready UI deployment. The new Next.js 14 app (`ui-next/`) has no Dockerfile. The existing `Dockerfile.stack` references the old `ui/` directory with React/Vite build commands that won't work for Next.js.

## Goal

Create a production Dockerfile for the Next.js 14 UI with multi-stage build, standalone output, and proper caching.

## Prerequisites

- Phase 9 complete (ui-next fully functional)
- ui-next builds successfully with `npm run build`

## Tasks

### Task 1: Configure Next.js for Standalone Output
Update next.config.ts for production standalone output mode.

**File**: `ui-next/next.config.ts`
```typescript
// Add output: 'standalone' for Docker deployment
// Enables minimal production bundle without node_modules
```

### Task 2: Create Production Dockerfile
Multi-stage Dockerfile for Next.js with optimal caching.

**File**: `ui-next/Dockerfile`
```dockerfile
# Stage 1: Dependencies
FROM node:20-alpine AS deps
WORKDIR /app
COPY package*.json ./
RUN npm ci --legacy-peer-deps

# Stage 2: Build
FROM node:20-alpine AS builder
WORKDIR /app
COPY --from=deps /app/node_modules ./node_modules
COPY . .
ENV NEXT_TELEMETRY_DISABLED=1
RUN npm run build

# Stage 3: Production runner
FROM node:20-alpine AS runner
WORKDIR /app
ENV NODE_ENV=production
ENV NEXT_TELEMETRY_DISABLED=1

# Create non-root user
RUN addgroup --system --gid 1001 nodejs
RUN adduser --system --uid 1001 nextjs

# Copy standalone build
COPY --from=builder /app/public ./public
COPY --from=builder --chown=nextjs:nodejs /app/.next/standalone ./
COPY --from=builder --chown=nextjs:nodejs /app/.next/static ./.next/static

USER nextjs
EXPOSE 3000
ENV PORT=3000
ENV HOSTNAME="0.0.0.0"

CMD ["node", "server.js"]
```
