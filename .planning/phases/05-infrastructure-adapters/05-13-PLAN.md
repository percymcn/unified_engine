<objective>
Fix SQLAlchemy table redefinition errors blocking all 58 infrastructure tests.

Root Cause: Two model files (models.py and database_models.py) both define `User(Base)`
with `__tablename__ = "users"`. When infrastructure imports trigger both files to load,
SQLAlchemy throws "Table 'users' already defined for this MetaData" error.

Solution: Make repositories import from database_models.py consistently, avoiding
models.py entirely in the infrastructure layer.

Output: All 58 infrastructure tests can be collected and run.
</objective>
