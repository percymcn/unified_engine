# Phase 14 Plan 01: Landing Page Foundation & Hero Section

## Objective

Create the landing page foundation with a compelling hero section that converts visitors.

Purpose: Replace the dashboard redirect with a proper marketing landing page that showcases Tradeflow's value proposition.
Output: Root page with hero, navigation, and responsive layout.

## Context

### Current State
- Root `/` redirects to `/dashboard` (no landing page)
- `/pricing` exists with basic layout
- shadcn/ui and Tailwind CSS available
- Lucide icons available

### Design Direction
Modern 2026 SaaS landing page:
- Clean, spacious design with lots of whitespace
- Bold headline, clear value proposition
- Gradient accents (subtle purple/blue)
- Dark/light mode support via existing theme system

## Tasks

### Task 1: Create landing page header component
**File:** `ui-next/src/components/landing/header.tsx`
**Action:** Create

Create a sticky navigation header for landing pages:
- Logo/wordmark "Tradeflow" linked to /
- Navigation links: Features, Pricing, FAQ (scroll anchors)
- CTA buttons: "Log in" (ghost), "Get Started" (primary)
- Mobile: hamburger menu with Sheet component
- Transparent on scroll, solid on scroll down

```tsx
// Use existing shadcn components: Sheet, Button
// Mobile menu with Sheet from @/components/ui/sheet
// Navigation items as array for DRY
```

### Task 2: Create hero section component
**File:** `ui-next/src/components/landing/hero.tsx`
**Action:** Create

Create a compelling hero section:
- Main headline: "Route TradingView Signals to Any Broker"
- Subheadline: Brief value prop (1-2 sentences)
- Primary CTA: "Start Free" → /register
- Secondary CTA: "See Pricing" → #pricing (scroll)
- Visual: Abstract trading/signal flow illustration (CSS/SVG gradient shapes)
- Stats preview: "10,000+ signals routed" / "99.9% uptime" (hardcoded for now)

Design:
- Full viewport height (min-h-screen minus header)
- Centered content with max-w-4xl
- Animated gradient background blob (CSS animation)
- Responsive: stack on mobile, side-by-side on desktop if adding visual
