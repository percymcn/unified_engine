# Phase 14 Plan 03: Social Proof & Trust Signals Section

## Objective

Create social proof and trust signals sections to build credibility with visitors.

Purpose: Reduce purchase anxiety by showing reliability metrics and security badges.
Output: Stats banner and trust signals section.

## Context

### Stats to Show (hardcoded for now)
- **10,000+** Signals Routed
- **99.9%** Uptime
- **5** Brokers Supported
- **<100ms** Average Execution

### Trust Signals
- "256-bit SSL Encryption"
- "SOC 2 Compliant" (aspirational badge)
- "No API Key Exposure"
- "GDPR Compliant"

### Design Approach
- Stats: Large numbers with labels, horizontal scroll on mobile
- Trust: Badge-style icons with text, subtle background

## Tasks

### Task 1: Create stats component
**File:** `ui-next/src/components/landing/stats.tsx`
**Action:** Create

Create a stats banner component:

```tsx
const stats = [
  { value: "10,000+", label: "Signals Routed" },
  { value: "99.9%", label: "Uptime SLA" },
  { value: "5", label: "Broker Integrations" },
  { value: "<100ms", label: "Avg Execution" },
];

export function Stats() {
  return (
    <section className="py-16 bg-muted/50">
      <div className="container mx-auto px-4">
        <div className="grid grid-cols-2 md:grid-cols-4 gap-8 text-center">
          {stats.map((stat) => (
            <div key={stat.label}>
              <div className="text-4xl md:text-5xl font-bold text-primary">
                {stat.value}
              </div>
              <div className="text-sm text-muted-foreground mt-2">
                {stat.label}
              </div>
            </div>
          ))}
        </div>
      </div>
    </section>
  );
}
```

Optional: Add count-up animation when section enters viewport.

### Task 2: Create social proof / trust signals component
**File:** `ui-next/src/components/landing/social-proof.tsx`
**Action:** Create

Create trust signals section:

```tsx
import { Shield, Lock, Globe, CheckCircle } from "lucide-react";

const trustSignals = [
  { icon: Lock, text: "256-bit SSL Encryption" },
  { icon: Shield, text: "Bank-Grade Security" },
  { icon: Globe, text: "GDPR Compliant" },
  { icon: CheckCircle, text: "No API Key Exposure" },
];

export function SocialProof() {
  return (
    <section className="py-12 border-y">
      <div className="container mx-auto px-4">
        <p className="text-center text-sm text-muted-foreground mb-6">
          Trusted by traders worldwide
        </p>
        <div className="flex flex-wrap justify-center gap-6 md:gap-12">
          {trustSignals.map((signal) => (
            <div key={signal.text} className="flex items-center gap-2 text-sm">
              <signal.icon className="w-4 h-4 text-green-500" />
              <span>{signal.text}</span>
            </div>
          ))}
        </div>
      </div>
    </section>
  );
}
```
