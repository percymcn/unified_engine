## Tasks

### Task 1: Create Symbol Aliases API endpoints

**What:** Backend API for managing symbol aliases.

**Files:**
- `app/routers/symbol_aliases.py` - New router
- `app/application/dto/symbol_alias_dto.py` - DTOs

**Implementation:**
```python
# Endpoints:
# GET /symbol-aliases - List all user's aliases (grouped by broker)
# GET /symbol-aliases/{broker_type} - List aliases for specific broker
# POST /symbol-aliases - Create new alias
# PUT /symbol-aliases/{id} - Update alias
# DELETE /symbol-aliases/{id} - Delete alias

@router.get("/", response_model=List[SymbolAliasGroupResponse])
async def get_symbol_aliases(
    current_user: User = Depends(get_current_user),
    alias_service: SymbolAliasService = Depends()
):
    """Get all symbol aliases grouped by broker."""
    return await alias_service.get_aliases_by_user(current_user.id)

@router.post("/", response_model=SymbolAliasResponse)
async def create_symbol_alias(
    request: CreateSymbolAliasRequest,
    current_user: User = Depends(get_current_user),
    alias_service: SymbolAliasService = Depends()
):
    """Create a new symbol alias."""
    return await alias_service.create_alias(current_user.id, request)
```

**Acceptance:**
- CRUD endpoints for symbol aliases
- User isolation enforced
- Validation prevents duplicate mappings
- Returns grouped response for UI
