## Technical Approach

### MetaAPI Cloud SDK Overview

MetaAPI provides a cloud-based API for MT4/MT5 trading with:
- **Streaming API**: Real-time terminal state via WebSocket
- **RPC API**: Request-response for trading operations
- **Same API**: Identical interface for MT4 and MT5

Key SDK classes:
- `MetaApi(token)` - Main entry point
- `account.get_streaming_connection()` - WebSocket streaming
- `account.get_rpc_connection()` - RPC operations
- `connection.terminal_state` - Local cache of positions/orders/account

### Integration Pattern

Follow established dual-mode pattern from Phase 17 (ProjectX SDK):
1. Create `MetaAPISDKService` - wrapper service
2. Update executors with SDK_AVAILABLE flag
3. SDK preferred, fallback to existing httpx implementation
4. Graceful degradation when SDK not installed

### Task 2: Create MetaAPI SDK Service

**File**: `app/services/metaapi_sdk_service.py`
**Creates**: New SDK wrapper service

**Implementation**:
```python
from metaapi_cloud_sdk import MetaApi

class MetaAPISDKService:
    """Wraps metaapi-cloud-sdk for MT4/MT5 trading"""

    def __init__(self, token: str, account_id: str):
        self.token = token
        self.account_id = account_id
        self._api: Optional[MetaApi] = None
        self._connection = None
        self._is_connected = False

    async def connect(self) -> bool:
        """Connect and synchronize with MetaAPI"""
        self._api = MetaApi(token=self.token)
        account = await self._api.metatrader_account_api.get_account(self.account_id)
        self._connection = account.get_streaming_connection()
        await self._connection.connect()
        await self._connection.wait_synchronized()
        self._is_connected = True
        return True

    async def get_account_info(self) -> Dict[str, Any]:
        """Get account information from terminal state"""
        return self._connection.terminal_state.account_information

    async def get_positions(self) -> List[Dict]:
        """Get open positions from terminal state"""
        return self._connection.terminal_state.positions

    async def create_market_buy_order(self, symbol, volume, sl, tp) -> Dict:
        """Place market buy order"""
        return await self._connection.create_market_buy_order(
            symbol=symbol, volume=volume, stop_loss=sl, take_profit=tp
        )

    # ... similar methods for all order types
```

**Key features**:
- Streaming connection (real-time state sync)
- Terminal state for positions/orders/quotes
- All order types supported (market, limit, stop, stop-limit)
- Position modification and close
- Health monitoring

### Task 4: Update MT4 Executor for dual-mode

**File**: `app/brokers/mt4_executor.py`
**Changes**:
- Import MetaAPISDKService with SDK_AVAILABLE flag
- Add `_sdk_service` property
- Update `initialize()` to try SDK first, fallback to httpx
- Add `is_using_sdk` property
- Delegate trading operations to SDK when available

**Pattern** (from projectx_executor.py):
```python
try:
    from app.services.metaapi_sdk_service import MetaAPISDKService, SDK_AVAILABLE
except ImportError:
    SDK_AVAILABLE = False
    MetaAPISDKService = None

class MT4Executor:
    async def initialize(self) -> bool:
        if SDK_AVAILABLE and self._has_metaapi_credentials():
            try:
                self._sdk_service = MetaAPISDKService(
                    token=self.metaapi_token,
                    account_id=self.metaapi_account_id
                )
                if await self._sdk_service.connect():
                    self._using_sdk = True
                    return True
            except Exception as e:
                logger.warning(f"SDK failed, falling back to httpx: {e}")

        # Fallback to existing httpx implementation
        return await self._initialize_httpx()
```

def get_quote(self, symbol: str) -> Optional[Dict]:
    """Get current quote from terminal state"""

@property
def health_status(self) -> Dict:

## Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| MetaAPI service latency | Use streaming API for real-time state |
| MetaAPI downtime | Dual-mode allows fallback to direct Manager API |
| Rate limits | SDK handles rate limiting internally |
| Token expiration | Use account access tokens with auto-refresh |

## Rollback Plan

1. Set `METAAPI_TOKEN=""` to disable SDK mode
2. Executors automatically fall back to httpx implementation
3. No database changes required
4. Remove `metaapi-cloud-sdk` from requirements to fully roll back
