# Plan 19-02: Frontend Connection Status UI

## Objective

Enhance the broker connection UI with three-state status indicators, a test connection button in the account form, and clear error messages throughout.

## Context

**Phase Requirements:**
- CONN-01: Connection status indicators (green/amber/red) for each broker
- CONN-02: Connection test button to validate credentials before save
- CONN-05: Last sync timestamp visible per account (ALREADY DONE in AccountCard)
- CONN-06: Clear error messages on connection failure

**Discovery Findings:**
- `BrokerHealthCard` currently only shows green (connected) or red (disconnected)
- Need amber state for "connecting", "checking", or "degraded"
- `AccountCard` already shows last_sync timestamp - CONN-05 satisfied!
- `AccountForm` has no test button - credentials are saved blindly
- Error messages are generic (e.g., "Failed to create account")

**Existing Components:**
- `ui-next/src/components/brokers/broker-health-card.tsx` - Status card
- `ui-next/src/components/accounts/account-form.tsx` - Account creation form
- `ui-next/src/components/accounts/account-card.tsx` - Account display
- `ui-next/src/lib/api/accounts.ts` - API functions

### Task 2: Add Test Connection button to account form

**What:** Add a "Test Connection" button to AccountForm that validates credentials before saving, showing results inline.

**Files:**
- `ui-next/src/lib/api/accounts.ts` - Add testConnection function
- `ui-next/src/components/accounts/account-form.tsx` - Add test button and state

**Acceptance:**
- "Test Connection" button appears after credentials are entered
- Button disabled until all required credential fields are filled
- Shows loading state during test
- Shows success message with green check on success
- Shows error message with red X on failure, with specific reason
- Does NOT save account - just tests credentials
- Can still save account even if test fails (user's choice)

### Task 3: Improve error messages throughout

**What:** Replace generic error messages with specific, actionable ones in account operations.

**Files:**

- `ui-next/src/components/accounts/account-card.tsx` - Update sync error handling
- `ui-next/src/components/accounts/account-form.tsx` - Update form error handling

**Acceptance:**
