# Plan 08-02: Broker Health Cards

## Context

Phase 8 requirement UI-05: Broker connection health monitoring. This plan creates broker health status cards showing connected/disconnected state for each configured broker (MT4, MT5, TradeLocker, Tradovate, TopStep/ProjectX).

## Goal

Build broker health cards that display connection status for all configured brokers, with visual indicators for connected/disconnected state.

## Prerequisites

- Plan 08-01 complete (signals table pattern established)
- Backend `/health` endpoint returns broker status
- Backend `/status` endpoint returns detailed broker info

## Tasks

### Task 1: Create Broker Types
Create TypeScript types for broker health data.

**File**: `ui-next/src/types/broker.ts`
```typescript
export type BrokerType = 'mt4' | 'mt5' | 'tradelocker' | 'tradovate' | 'projectx';

export interface BrokerHealth {
  name: BrokerType;
  connected: boolean;
  lastSeen?: string;
  error?: string;
}

export interface HealthStatus {
  status: 'healthy' | 'unhealthy';
  redis: 'connected' | 'disconnected';
  brokers: Record<string, boolean>;
}
```
