# Plan 08-04: Real-time WebSocket Integration

## Context

Phase 8 success criterion: "Dashboard updates in real-time without page refresh." This plan integrates WebSocket connections to push updates for signals, trades, and broker health to the UI.

## Goal

Implement WebSocket client in Next.js that connects to backend `/ws` endpoint and updates UI components in real-time when signals, trades, or broker status changes.

## Prerequisites

- Plans 08-01, 08-02, 08-03 complete (all UI components built)
- Backend WebSocket endpoint `/ws` working
- Backend WebSocket manager sends signal_update, order_update, position_update, account_update events

  | 'order_update'
  | 'position_update'
  | 'account_update'
  | 'heartbeat'
  | 'error';

export interface WebSocketMessage<T = unknown> {
  type: WebSocketMessageType;
  data: T;
  timestamp: string;
}
