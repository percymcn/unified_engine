         - __init__(db: Session)
         - check_duplicate_entry(account_id, symbol, action) -> DuplicateCheckResult:
           - If action is CLOSE/EXIT: return DuplicateCheckResult(is_duplicate=False)
           - Query open positions for account + symbol
           - If position exists with same direction: return DuplicateCheckResult(is_duplicate=True, reason="position_already_open")

           - If no position: return DuplicateCheckResult(is_duplicate=False)
         - get_open_positions(account_id, symbol) -> List[Position]
       - DuplicateCheckResult dataclass:
         - is_duplicate: bool
         - reason: Optional[str]
         - existing_position_id: Optional[int]
    2. Use in-memory position tracking from Phase 22 OR query ExecutionLog
    3. Handle edge cases: partial positions, pending orders

  <action>
