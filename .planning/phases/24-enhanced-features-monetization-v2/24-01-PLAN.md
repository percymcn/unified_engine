<task type="auto">
  <name>Task 2: Create trial service with enforcement</name>
  <files>app/services/trial_service.py, app/routers/trial.py, app/main.py</files>
  <action>
    1. Create app/services/trial_service.py:
       - TrialService class with methods:
         - start_trial(user) - Set trial_started_at = now, trial_status = "active"
         - increment_trade_count(user) - Add 1 to trial_trade_count
         - check_trial_status(user) -> TrialStatus:
           - If subscription_tier != "free": return TrialStatus.NOT_APPLICABLE
           - If trial_status == "pending": return TrialStatus.NOT_STARTED
           - If trial_status == "expired": return TrialStatus.EXPIRED
           - If trial_trade_count >= 100: return TrialStatus.EXPIRED
           - If now - trial_started_at > 3 days: return TrialStatus.EXPIRED
           - Else: return TrialStatus.ACTIVE
         - get_trial_info(user) -> dict:
           - trades_remaining: max(0, 100 - trial_trade_count)
           - days_remaining: max(0, 3 - (now - trial_started_at).days)
           - status: TrialStatus
         - expire_trial(user) - Set trial_status = "expired", trial_ended_at = now
       - TrialStatus enum: NOT_STARTED, ACTIVE, EXPIRED, NOT_APPLICABLE
    2. Create app/routers/trial.py:
       - GET /api/trial/status - Return trial info for current user
       - Uses get_current_user dependency
    3. Register router in app/main.py
  </action>
  <verify>curl -H "Authorization: Bearer $TOKEN" http://localhost:8765/api/trial/status returns trial info</verify>
  <done>Trial service tracks and reports trial status</done>
</task>

<task type="auto">
  <name>Task 3: Integrate trial enforcement into signal processor</name>
  <files>app/services/signal_processor.py</files>
  <action>
    1. Import TrialService in signal_processor.py
    2. Before executing signal (before risk checks):
       - trial_service = TrialService(db)
       - trial_status = trial_service.check_trial_status(user)
       - If trial_status == TrialStatus.EXPIRED:
         - Reject signal with reason "trial_expired"
         - Log rejection to RejectedSignal table
         - Return early with error response
       - If trial_status == TrialStatus.NOT_STARTED:
         - trial_service.start_trial(user) - Auto-start on first signal
    3. After successful signal execution:
       - If user.subscription_tier == "free":
         - trial_service.increment_trade_count(user)
         - If trial_trade_count >= 100: trial_service.expire_trial(user)
    4. Don't block paid users (subscription_tier != "free")
  </action>
  <verify>Execute test signal with free user, verify trial_trade_count increments</verify>
  <done>Signal processor blocks expired trials, tracks trade count</done>
</task>
