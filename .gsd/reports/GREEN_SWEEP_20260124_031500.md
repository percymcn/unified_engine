## What Was Broken

### 1. SessionFactory Compatibility Error (CRITICAL)
- **Issue:** `app/infrastructure/container.py` was calling `self._session_factory.create()` but SessionFactory only provides `create_session()` method
- **Impact:** Account creation and listing endpoints returned 500 errors with `AttributeError: 'SessionFactory' object has no attribute 'create'`
- **Location:** 5 occurrences in `app/infrastructure/container.py`:
  - Line 145: `_get_repositories()`
  - Line 158: `_get_symbol_alias_repository()`
  - Line 288: `_get_account_group_repository()`
  - Line 293: `update_account_settings_use_case()`
  - Line 298: `get_account_settings_use_case()`

### 2. ProjectX DNS Error Messaging (MINOR)
- **Issue:** DNS resolution failures for `gateway-api.s2f.projectx.com` returned generic "connection error" messages
- **Impact:** Unclear whether error was DNS/network issue vs authentication failure
- **Location:** `app/application/use_cases/test_connection.py` - `_test_projectx()` method
